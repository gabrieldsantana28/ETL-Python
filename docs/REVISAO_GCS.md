# Revisão do Plano de GCS

## Objetivo
Validar o processo de controle de mudanças
e revisão de código do projeto ETL-Python.

## Procedimento
As alterações devem ser realizadas em
branches específicas e integradas à main
por meio de Pull Requests.

## Aprovação
Toda alteração deverá passar pela revisão
de um colaborador antes da integração.
