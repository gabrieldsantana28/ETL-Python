# Política de colaboração

1. Não realizar commits diretamente em `main`.
2. Criar branches `feature/`, `fix/` ou `docs/` a partir de `main`.
3. Abrir Pull Request com descrição, teste realizado e referência a Issue, se houver.
4. Solicitar revisão de colaborador com acesso Write; aguardar aprovação exigida pelo Ruleset.
5. Evitar segredos e dados sensíveis em commits, logs e capturas.
6. Depois do merge, registrar a alteração no histórico e criar baseline por tag quando necessário.
